# よみフラッシュ

読みの練習用WEBゲームです。

## 主な機能

- 清音
- 濁音
- 半濁音
- 促音
- 長音
- 拗音
- カタカナ
- 漢字1年
- 漢字2年
- 単音／単語
- 単語は最大5文字まで
- 問題数モード
- 時間モード
- ランダム出題
- 横書き／縦書き
- UDデジタル教科書体を優先表示
- 目標設定
- 称号
- ランキング保存

## ファイル構成

```text
/
├─ index.html
├─ dictionary.js
├─ README.md
├─ .gitignore
└─ data/
   ├─ dictionary.csv
   └─ dictionary_master.xlsx
```

## GitHubへのアップロード

1. GitHubで新しいリポジトリを作成します。
2. このZIPを展開します。
3. 中にあるファイルと `data` フォルダをすべてアップロードします。
4. Commit changes を押します。

## GitHub Pagesで公開

1. リポジトリの `Settings` を開きます。
2. 左側の `Pages` を選びます。
3. `Build and deployment` の Source を `Deploy from a branch` にします。
4. Branch を `main`、フォルダを `/ (root)` にします。
5. `Save` を押します。
6. 公開URLが表示されたら、そのURLからゲームを開けます。

## 辞書の管理

WEBゲームが実際に読む辞書は `dictionary.js` です。

語彙を追加・整理するときは、基本的に

`data/dictionary_master.xlsx`

を編集して管理します。

`data/dictionary.csv` はGitHub上でも確認しやすい一覧です。

現在の辞書は漢字2年生までを対象にしています。

## 注意

`index.html` と `dictionary.js` は必ず同じフォルダに置いてください。

ランキングは各端末のブラウザ内に保存されます。
辞書データ自体はブラウザには保存されません。

## 表示フォント

読みカードの文字は Webフォントの `Klee One` を最優先で使用します。
Chromebook側に教科書体フォントが入っていなくても、インターネット接続時は同じフォントで表示されます。

フォント読み込み先:
Google Fonts

フォント:
Klee One

オフライン時やGoogle Fontsへ接続できない環境では、
端末に入っているUDデジタル教科書体 → BIZ UDPGothic → Yu Gothic の順に切り替わります。

## 追加仕様

- 清音・濁音・半濁音の4文字・5文字語を増量
- 単語の長さ設定は、選択文字数が80%以上出題されるよう調整
- 2文字設定は100% 2文字
- 3〜5文字設定は選択文字数を約82%、それより短い語を約18%
- 短文読みモード
  - 1年生
  - 2年生
  - 3年生
  - 漢字にはルビ表示
- 漢字1年・漢字2年の問題では、「読めた！ 次へ」を押したあと約1秒読みを表示してから次へ進む

## フリガナ表示・重複出題の改善

- 漢字問題では「読めた！ 次へ」を押すと、その漢字の上にフリガナが約1秒表示されます。
- 「読みを確認」という表示は使いません。
- 読みデータのある漢字だけを出題します。
- 同じ問題は、出題プールを一巡するまでは再出題しません。
- 短文は各学年40問に増量しました。

## 辞書の品質見直し

- 実在し、1・2年生が意味をイメージしやすい語を優先
- 不自然な合成語・意味の取りにくい語を削除
- 各カテゴリは最大100語
- 漢字語も学校生活・日常生活で出会いやすい語に限定
- 短文も各学年最大100問

## レベル制

単語の長さ設定をレベル制に変更しました。

- レベル1：1文字
- レベル2：2文字のみ
- レベル3：3文字まで（3文字を80%以上）
- レベル4：4文字まで（4文字を80%以上）
- レベル5：5文字まで（5文字を80%以上）

## 短文

機械的な主語＋述語の組み合わせは使用せず、
学校・家庭・遊び・食事・移動など、日常生活で自然に使う文だけに整理しました。
各学年50文です。

## 文字間隔

読みカードの文字間を狭く調整しました。
単語・漢字・縦書き・短文とも、文字が離れすぎない自然な表示にしています。

## 設定拡張
- レベルはひらがな・カタカナ専用
- 漢字選択時はかなカテゴリを自動解除・無効化
- 短文選択時は文字カテゴリとレベルを無効化
- 漢字3年を追加
- 短文のルビあり／なしを選択可能
- 短文の縦書きは高さを制限し、折り返して複数列表示
- 文字サイズ 小・中・大を選択可能

## 縦書き短文の自動折り返し

- 短文の縦書きは、1列で画面内に収まる場合はそのまま表示
- 画面からはみ出す場合だけ自動で2列に折り返します

## 学年外漢字・短文表示の改善

- 短文で設定学年より上の漢字が含まれる場合、ルビ設定が「なし」でもその漢字には強制的にルビを表示
- 例：1年生設定で「虫歯」が出る場合、「歯」には必ずルビを表示
- 短文の文字サイズ「小・中・大」の差を大きく調整
- 短文は横方向中央寄せ、縦方向は上詰め

## 縦書き短文の折り返し修正

- 段組み方式を廃止
- 上から下へ自然に流れる教科書型の縦書き
- 1列に収まらない場合だけ次の列へ折り返し
- 文節単位ではなく、文字位置に応じて自然に改行
- 常に上詰め
- 大きい文字でも上下が切れにくい表示に変更

## メニュー構成の変更

- 最初に「ひらがな・カタカナ／漢字／短文」を選択
- ひらがな・カタカナを選んだ場合だけ、次に文字種とレベルを選択
- 漢字は1年・2年・3年のいずれか1つだけ選択
- 短文は学年とルビの有無を選択
- 縦書き短文は折り返した列も必ず上詰め
- 文節ではなく通常の縦書きと同じく文字位置で折り返し

## スタートボタン修正

- 新しい選択式メニューに合わせて開始処理を整理
- 旧メニューのDOM参照を削除
- ひらがな・カタカナ／漢字／短文それぞれの開始条件を修正
- JavaScript構文チェック済み

## v4 実行時エラー修正

スタートできない原因だった旧設定用 `updateExclusiveSettings()` 呼び出しを削除しました。
また、読み種類の表示切替関数 `updateTypePanels()` をグローバル化し、
初期化・再設定時のどちらからも安全に呼べるようにしています。
JavaScript構文チェック済みです。

## v5 設定変更

- 「自分の目標」を削除
- 短文に「分かち書き あり／なし」を追加
- 「なし」では単語間のスペースを削除して通常の文章表示
- 縦書きを選んだ場合は、開始前に「タブレットを縦にしてください」と表示
- 画面が縦向きになったことを確認してからスタート可能

## v6 短文表示ルール

- 「目標まであと○秒」などの目標表示を削除
- ルビは「あり／なし」の設定だけで表示を決定
- 未習漢字だからといってルビを強制表示しない
- 学年外漢字を含む語で読みデータがある場合は、その語をひらがな表示
- 語単位の読みがない場合も、読みデータがある漢字は可能な範囲でひらがなへ置換

## v7 未習漢字の部分かな化

学年外の漢字を含む語は、語全体をひらがなにせず、
既習漢字を残して未習部分だけひらがなにします。

例:
- 1年生設定「虫歯」→「虫ば」

文脈によって読みが変わる語は、個別データを優先します。

## v8 横書き短文・横画面続行

- 横書き短文は、折り返した2行目以降も含めてすべて左寄せ
- 短文全体はカード内で中央位置に置き、文章自体は左揃え
- 縦書き開始前の注意画面に「このまま横画面でする」ボタンを追加
- パソコンなど画面を縦向きにできない場合でも、そのまま縦書き表示で開始可能

## v9 漢字の送り仮名・問題数

- 漢字問題で必要な送り仮名を含めて表示
  - 例：送 → 送る
  - 読 → 読む
  - 食 → 食べる
  - 強 → 強い
- 問題数は 5 / 10 / 15 / 20 / 30 問に整理
- 30問を最大に変更

## v10 漢字の読み表示と送り仮名

漢字の読みを表示するとき、送り仮名を消さずに残すよう修正しました。

例:
- 軽い → 軽（かる）い
- 読む → 読（よ）む
- 食べる → 食（た）べる
- 送る → 送（おく）る
